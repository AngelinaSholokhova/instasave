# InstaSave

Android-приложение: вставьте ссылку на публичный **Reel или видео-пост Instagram** — видео сохранится в галерею.

## Возможности

- Вставка ссылки из буфера обмена и по кнопке «Вставить».
- «Поделиться → InstaSave» прямо из приложения Instagram.
- Открытие ссылок `instagram.com/...` сразу в приложение.
- Каскадирование **всех** видео из мультипоста (карусели).
- Прогресс-бар, отмена, история загрузок, уведомление о сохранении.
- Превью видео в списке загрузок, тап по готовой задаче открывает видео в галерее.
- Проверка обновлений: при старте приложение спрашивает GitHub о новой версии и предлагает обновиться.

## Настройки

- **Качество видео** — максимальное / среднее / экономное.
- **Папка в галерее** — своё имя папки внутри `Movies`.
- **Не дублировать ролики** — пропускать уже скачанные.
- **Автозагрузка из шаринга** — качать сразу или только подставлять ссылку.
- **Уведомления** — сообщать, когда видео сохранено.
- **Очистка истории** — кнопка в настройках.

## Ограничения

- Работает только с **публичными** постами. Приватные аккаунты, Stories и прямые эфиры не поддерживаются.
- Instagram может временно ограничивать анонимный доступ — в этом случае подождите несколько минут.
- В России/где Instagram заблокирован — включите VPN, иначе приложение не сможет подключиться.

## Сборка

Локально (нужны JDK 17 и Android SDK):

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
./gradlew installDebug   # установка на подключённый телефон по USB
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Release-сборка с подписью

Чтобы друзья могли ставить приложение и обновлять его поверх, нужен release-APK,
подписанный постоянным ключом. Ключ создаётся один раз:

```bash
keytool -genkeypair -v -keystore keystore/instasave.keystore -alias instasave \
  -keyalg RSA -keysize 2048 -validity 10950
```

Пароли кладутся в `keystore.properties` (файл в `.gitignore`, в репозиторий не попадает):

```properties
storeFile=keystore/instasave.keystore
storePassword=...
keyAlias=instasave
keyPassword=...
```

Затем: `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`.

**Важно:** не теряйте keystore. Без него нельзя выпустить обновление поверх уже
установленной версии — друзьям придётся сносить приложение и ставить заново.

## CI (GitHub Actions)

На каждый push в ветку запускаются тесты и собираются APK
(вкладка Actions → последний запуск → Artifacts).

Подпись release-сборки берётся из секретов репозитория (Settings → Secrets → Actions):

| Секрет | Что внутри |
| --- | --- |
| `KEYSTORE_BASE64` | `base64 -w0 keystore/instasave.keystore` |
| `KEYSTORE_PASSWORD` | пароль keystore |
| `KEY_ALIAS` | `instasave` |
| `KEY_PASSWORD` | пароль ключа |

По тегу `v*` создаётся Release с подписанным APK — именно его видит приложение,
когда предлагает обновиться.

## Релиз новой версии

1. В `app/build.gradle.kts` поднимите `versionCode` (+1) и `versionName` (например `1.1`).
2. Закоммичьте и запушьте.
3. Создайте тег и отправьте: `git tag v1.1 && git push origin v1.1`.
4. CI соберёт APK и опубликует его в Releases — друзьям приложение само предложит обновиться.
